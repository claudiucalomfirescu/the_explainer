### Findings

1. **Blocking, fixed (layout, caught by the phone test).** At 375 px the controls column shrank
   to about 40 px beside the grid and its buttons pushed the page sideways (document 473 px wide).
   The column now has a minimum width and wraps under the grid; probe H8 guards it.
2. **Blocking, fixed (embed) with a declared test correction.** The iframe pointed at
   `explainers/transformer/index.html`, which the local static server answers with a 301 to a
   clean URL. Vercel and GitHub Pages answer 200, but relying on that is fragile. The iframe now
   points at the folder (`explainers/transformer/`), which every host serves directly. The
   test's expected `src` changed accordingly; its rule that the first response must be HTTP 200
   is unchanged. The reason is written in the test.
3. Checked, no change: the energy shown in the widget matches the formula (the letter H alone:
   −(25 × 24)/2 = −300, seen in the screenshot).
4. Checked, no change: the widget's buttons are at least 44 px, so they pass WCAG 2.2 target size.
   The axe scan on the open widget reports nothing serious or critical.
