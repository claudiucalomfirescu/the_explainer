### Findings

1. **Blocking, fixed (test correction, declared).** The "scroll the new card into view" test
   hard-coded perceptron → Hopfield as the "next" link, which stopped being true once the 1969
   card existed. It now follows the Hopfield card's own next link. Re-probed (E4, E8): CAUGHT.
2. **Blocking, fixed (probe harness).** The C1 probe's anchor matched twice, so the runner skipped
   it, and it printed nothing because skips were only listed in the final JSON. The runner now
   prints every broken probe, and a mutation that breaks the build is now reported as
   **BROKEN PROBE**, no longer as "CAUGHT (build failed)". Phase 1's E4 showed the same false catch.
3. **Should-fix, fixed (checker).** arXiv's API rate-limits and drops connections. The checker
   now reads the arXiv record from the abstract page's own `citation_*` meta tags, falling back to
   the API with spaced retries. The new path got its own test, written before it was relied on.
4. **Should-fix, fixed (content).** Author lists of the GPT-3 and InstructGPT papers were partial
   without saying so; they now end "and 26 more authors" / "and 15 more authors".
5. **Should-fix, fixed (component).** On cards with two papers, the note read "The paper had more
   authors"; it now says "These papers had".
6. **Accuracy fixes applied while writing** (each against the paper or its record): Papert
   co-created Logo; Rumelhart co-led the PDP group with McClelland; Teh's 2006 affiliation is the
   National University of Singapore (the paper's own); the deep belief net result is stated with
   its qualifier (best among methods with no built-in knowledge of images, 1.25 percent); the
   attention alignment example is the paper's own figure ("European Economic Area"); the 2020
   summaries work is attributed to OpenAI alone; the LSTM idea no longer mentions forgetting,
   because the forget gate came in 2000.
