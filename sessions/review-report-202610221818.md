### Findings

1. **Blocking, fixed (test correction, declared).** E4 MISSED: the "scroll the new card into
   view" test passed with the scroll code disabled. At 1280 × 800, moving to a shorter card made
   the browser clamp the scroll position, so the card top landed in view by accident. The
   expectation was re-derived from REQ-2 (the top must be in the viewport after navigating from a
   position where it would not be), not from the failing run. The test now uses a 400 px tall
   viewport and the link to the long Hopfield card, and asserts the page was scrolled past 1000 px
   before the click. Re-probed: CAUGHT. The reason is recorded in the test's own comment.
2. **Blocking, fixed (test corrections, declared, before the UI existed).** The red run against
   the bare scaffold showed two tests passing for the wrong reason. "Each marker sits inside its
   era" passed with zero markers, and now requires at least four. The axe scan of `/perceptron/`
   passed on the 404 page, and now asserts the card exists first.
3. **Blocking, fixed (test correction, declared, before the validator existed).** The "later
   inspiration" unit test planted a fixture with `order: 0`, which the schema rejects, so the test
   died in its own setup. It now has the first milestone cite the second.
4. **Blocking, fixed (implementation).** Share images exported through the `opengraph-image`
   file convention had no file extension, so `serve` (and GitHub Pages) would send them without an
   image content type; the share-tag test caught it. Replaced by `app/og/[file]/route.tsx` writing
   `/og/<slug>.png`; the old files are in `archive/og-file-convention/`.
5. **Should-fix, fixed.** On first load at phone width the strip glided to the active marker, so a
   shared link showed the wrong part of the timeline for a moment (seen in a screenshot). The
   first positioning is now instant.
6. **Should-fix, fixed.** Uppercase era labels rendered "1940S–50S". Labels are now in normal case.

### Architecture re-gate

`docs/architecture.md` changed three times after its Step 5 gate, each reviewed here against the
spec. The people registry became a list, because `JSON.parse` keeps only the last of two equal
keys, so REQ-9's duplicate-id rule would be untestable. Share images became a `.png` route
(finding 4). `cacheComponents` is off, because it keeps hidden copies of previous pages in the DOM
and REQ-2 asks for one card. All three serve requirements already in the spec; none changes one.

pages of McCulloch and Pitts (1943), Rosenblatt (1958) and Hopfield (1982), and the Psychology Press
reissue record of Hebb (1949). Biographical notes were written from general knowledge and are
hedged where the record is contested ("usually credited to Carla Shatz"). Phase 2's link checker
(REQ-11) re-checks every paper mechanically.
